# ConversorTime_Julian

• El propósito del proyecto (ConversorTime básico).

    El usuario podra convertir distos tipos de horas para poder saber su equivalente.


• Tecnologías utilizadas.

    Se uso como lenguaje Java, con el cual nos permite unicamente tener un solo archivo

• Instrucciones de uso.

    El usuario podra escoger entre cualquiera de las cuatro distintas opciones (1. Horas a minutos 2. Minutos a segundos 3. Días a horas 4. Semanas a días) despues podra ingresar la fecha solicitada y mostrara el resultado segun la opcion elegida.
